# 🎨 Color Palette Generator

A modern and responsive **Color Palette Generator** built with **HTML, CSS, and JavaScript**. Generate beautiful random RGB color palettes with a single click and instantly copy individual colors or the entire palette.

🔗 **Live Demo:** *https://rgb-color-palette-generator.vercel.app*

## ✨ Features

- 🎨 Generate 5 random RGB colors
- 📋 Copy a single color by clicking on a color box
- 📑 Copy the entire color palette with one click
- ⚠️ Validation to prevent copying before generating colors
- 🎭 Smooth hover effects and subtle animations
- 🌙 Modern dark theme UI
- 📱 Fully responsive design
- ♿ Improved button interactions and accessibility
